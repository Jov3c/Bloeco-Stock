# BlockecoExchange 简体中文本地化设计

## 目标

将 BlockecoExchange Phase 1 的玩家提示、命令元数据、默认配置和运维 README 本地化为简体中文，使原版客户端玩家在不安装资源包或模组的情况下得到完整的中文交互反馈。

## 范围与边界

- 保持现有命令名称和参数不变：`/company create`、`/company info`、`/company recovery list`。这避免破坏 Paper 命令习惯、权限节点和既有脚本。
- 将 `messages.*` 默认值、`Messages` 的兜底文本、`plugin.yml` 的命令描述/用法和 `README.md` 改为简体中文。
- 公司状态与恢复状态在玩家输出中映射为中文显示名；数据库中保存的稳定枚举名、审计事件类型、配置键和权限节点保持不变。
- 本地 `run/plugins/BlockecoExchange/config.yml` 同步更新，使当前测试服重启后立即使用中文。
- Paper、Vault、EssentialsX 等第三方插件的日志或消息不在本插件控制范围内；不修改第三方 JAR 或其运行时逻辑。

## 方案选择

推荐采用“配置驱动 + 显示层映射”：继续由 `Messages` 读取 `messages.*`，只在显示边界把枚举状态映射为中文。相比把中文散落到命令处理器，这保留服主自行修改文案的能力，并保证持久化/审计使用稳定的英文技术标识。

## 验证

- 为中文默认文案、缺失配置的中文兜底和所有状态显示映射添加单元测试。
- 验证玩家可见的创建、查询、恢复、权限和失败路径均不含本插件遗留英文。
- 用 `clean test shadowJar --rerun-tasks --no-build-cache` 验证构建，并部署到本地 Paper 测试服，检查启动后的中文配置与命令响应。

## 非目标

- 不新增中文命令别名。
- 不翻译数据库枚举、审计事件或第三方服务器日志。
- 不改变股票交易或公司注册的业务规则。

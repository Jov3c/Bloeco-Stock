# IPO 上市与 `/stock` 烟测

## 可自动验证

在本工作树执行：

```powershell
.\gradlew.bat clean test shadowJar
```

该命令覆盖迁移、公开读取、缓存、命令 gate 和现有认购 saga 的自动化测试，并产出 `build/libs/blockstock-*-all.jar`。

服务器启动成功且没有上市公司时，控制台可执行：`/stock market`。预期中文结果为“当前暂无已上市股票。”这是可执行的公开空市场检查，不等同于真实 IPO 验收。

## 真实玩家 IPO（本次未执行）

真实关闭 IPO 需要已认证玩家、可用 Vault 经济提供方、可验证的公司资产和实际资金。未捕获这些真实环境证据时，不得将创建公司、公告 IPO、等待开放、玩家认购、关闭上市、获得代码，或后续 `/stock` 查询标为通过。

本次实现仅记录自动化构建和可执行的 console 空市场检查；真实玩家 IPO 烟测为**未执行**，由部署人员在受控服务器上完成。

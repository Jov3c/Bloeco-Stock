# Bloeco-Stock 功能与验收范围

| 范围 | 已交付能力 | 验收入口 |
| --- | --- | --- |
| 客户端 | 仅服务端 Paper 插件，原版客户端可加入 | 加入服务器后打开 `/stock` GUI |
| 经济边界 | Bloeco 为唯一货币与 Vault provider；Stock 无第二货币 | Vault provider 日志与 Bloeco 总账 |
| 公司 | 创建、最低注册资本、资产绑定、公司账户和财报 | 公司中心 GUI、管理员配置 |
| IPO | 发行价、募资目标、2 天认购、上市与失败恢复 | IPO GUI、公告、恢复诊断 |
| 交易 | 限价买卖、撤单、成交、持仓、证券资金 | 行情 GUI、订单/成交记录 |
| 行情 | 分时、日 K、成交量、五档盘口、全市场市值 | 个股页面与市场总览 |
| 治理 | 15 天分红、亏损不分红、增发投票、回购、退市 | 公司治理 GUI 与公告 |
| 系统市场 | 10 家蓝筹、随机大盘/行业事件、持续做市 | 市场总览、公告、准备金状态 |
| 兼容 | 原生资产、领地和商店可选适配 | 资产绑定 GUI 和适配器日志 |
| 安全 | 持久化资金状态、审计、歧义冻结、恢复门禁 | `/company recovery list`、`/stockadmin recovery cash` |

非目标：货币发行、玩家总账、国库、税收、支付命令和 Vault Economy provider 均属于 Bloeco，不属于 Bloeco-Stock。
